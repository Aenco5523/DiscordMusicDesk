### 한국어

- 앱 화면, 설정, 재생 상태와 오류 메시지를 한국어·중국어 간체·일본어·영어로 표시합니다. 설정에서 언어를 바꾸면 즉시 적용되고 재시작 후에도 유지됩니다.
- Discord의 `/영상추가` 명령 이름·설명·응답에 영어·중국어 간체·일본어 현지화를 추가했습니다. 명령의 동작과 권한 확인은 그대로입니다.
- 설정에서 공식 안정판 yt-dlp 업데이트를 수동으로 확인할 수 있습니다. 업데이트를 검증한 뒤 적용하며 실패하면 기존 버전을 유지합니다.
- MIT 라이선스와 각 번들 도구의 라이선스 고지를 정리했습니다. Inno Setup 설치 프로그램과 설치 언어를 하나의 파일에 담았습니다.

### 简体中文

- 应用界面、设置、播放状态和错误提示支持韩语、简体中文、日语和英语。语言更改立即生效，并在重启后保留。
- Discord 的添加视频命令及回复提供英语、简体中文和日语本地化；原有权限检查保持不变。
- 可在设置中手动检查并验证官方稳定版 yt-dlp 更新。更新失败时继续使用原版本。
- 增加 MIT 许可说明以及随附工具的许可声明。四种安装语言合并在同一个安装文件中。

### 日本語

- アプリ画面、設定、再生状態、エラー表示を韓国語・簡体字中国語・日本語・英語に対応させました。言語の変更はすぐに反映され、再起動後も保持されます。
- Discord の動画追加コマンド名・説明・返信に英語・簡体字中国語・日本語のローカライズを追加しました。既存の権限確認は維持しています。
- 設定から公式安定版 yt-dlp の更新を手動で確認できます。検証後に適用し、失敗時は旧版を使い続けます。
- MIT ライセンスと同梱ツールのライセンス表示を整備しました。四つのインストール言語を一つのファイルにまとめています。

### English

- The app UI, settings, playback status and error messages now support Korean, Simplified Chinese, Japanese and English. Language changes apply immediately and persist across restarts.
- The Discord add-video command name, description and replies have English, Simplified Chinese and Japanese localizations. Existing permission checks remain in place.
- Settings can check for an official stable yt-dlp update on demand. An update is verified before use; a failed update leaves the previous executable available.
- Added the MIT license and notices for bundled tools. One Inno Setup file includes all four installer languages.

### 검증 / Validation

Biome 검사와 TypeScript 타입 검사 통과, 자동 테스트 68개 통과. 통합 설치 파일을 임시 폴더에 설치해 필수 파일을 확인하고, 중국어 간체 첫 실행·네 언어 전환·영어 설정 재시작 유지·1000×700 화면 배치를 확인했습니다. 패키지 앱에서 실제 공개 YouTube 영상의 첫 재생, PC 오디오 출력, 탐색 바 이동, 일시정지, 캐시 재실행과 세 가지 창 크기를 확인했습니다. 실제 Discord 서버 음성 송출과 명령 현지화는 봇 인증 정보 없이 검증하지 못했습니다.

Biome and TypeScript checks and all 68 automated tests passed. The installer was installed to an isolated folder; first-run Chinese, switching among all four languages, persisted English, and compact 1000×700 layout were checked. The packaged player passed real public-video playback, PC audio rendering, seek, pause, cached restart and three window sizes. Live Discord voice transmission and command localization still require bot credentials and a test channel.
