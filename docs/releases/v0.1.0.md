## Music Desk v0.1.0

### 다운로드

`Music-Desk-0.1.0-Portable.exe`를 받아 실행하세요. Windows x64용 설치 없는 포터블 앱이며 코드 서명은 없습니다.

### 한국어

- YouTube 영상과 재생목록을 앱에서 재생하고 순서대로 대기열에 추가합니다.
- 영상·재생목록·이전/다음 곡·일시정지·탐색 바·PC/Discord 개별 음량을 한 화면에서 제어합니다.
- 영상별 음량을 -16 LUFS와 -1.5 dBTP 목표로 평준화하고 같은 처리 파일을 PC와 Discord에 사용합니다.
- Discord 음성 채널 ID로 봇을 입장시키고, 같은 음성방 참가자가 `/영상추가 url`로 곡을 추가할 수 있습니다.
- 앱 아이콘과 1000×700 이상 창에 맞춘 레이아웃을 포함합니다.

### 사용 전 준비

Discord 봇 토큰과 서버 초대가 필요합니다. 초대에는 `bot`·`applications.commands` 범위와 음성 채널 보기·연결·말하기 권한을 부여하세요. 앱의 **설정**에서 토큰을 저장하고 메인 화면에 음성 채널 ID를 입력합니다.

### 검증

Biome 검사와 TypeScript 타입 검사 통과, 자동 테스트 57개 통과. 패키지 앱에서 실제 공개 YouTube 영상의 첫 재생, PC 오디오 출력, 탐색 바 이동, 일시정지, 재실행, 1000×700·1320×860·1600×700 창 배치가 통과했습니다. 실제 Discord 서버로의 음성 송출은 별도 계정 정보 없이 검증하지 못했습니다.

### 지원 범위와 파일 확인

공개 일반 영상(2시간 이하, 처리 파일 1GB 이하)과 최대 200곡 대기열을 지원합니다. 실시간·비공개·접근 제한 영상은 지원하지 않습니다.
